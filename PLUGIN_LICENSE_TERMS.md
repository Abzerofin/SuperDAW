# Plugin License Terms

## User Responsibility for Plugin Licensing Compliance

Plugins run only on machines where they are installed. **Each user is solely responsible for ensuring they comply with the license terms of any plugin they install, load, or use within SuperDAW.**

### How parameter values work

A SuperDAW project stores each plugin's parameter values as ordinary project data, shared like any other edit. A collaborator does not operate anyone else's copy of a plugin: they change a value in the shared project, and each machine's own installed copy reads that value locally, exactly as it would if the value had been typed in on that machine, loaded from a saved project, or recalled from a preset.

This means a collaborator who does not have a plugin installed can still change its parameter values, and the sound will change on the machines that do have it installed. Depending on the audio system in use, that change may be heard during playback rather than only after a track is frozen or exported; the arrangement is the same either way — no plugin is ever operated across the network, and no processed audio is sent between machines.

### Key Points

- **License Compliance**: You must own, license, or have permission to use any plugin installed on your machine, including when its parameter values are changed by collaborators in a session.

- **Third-Party Plugins**: SuperDAW is not responsible for third-party plugin licensing, activation, or usage compliance. Verify that your plugin licenses permit:
  - Use in your jurisdiction
  - Collaborative or networked usage
  - Parameter values authored by collaborators who do not hold a license for that plugin
  - Use with this specific DAW software

- **Your Choice**: Settings ▸ Collaboration lets you limit parameter adjustment to people who have the plugin installed. This setting applies to plugins installed on your machine; collaborators who hold their own license and run their own copy are unaffected by it. Use it if your plugin licenses do not permit the arrangement described above.

- **Your Liability**: SuperDAW creators assume no liability for plugin licensing violations. You are responsible for:
  - Reviewing plugin EULAs before using them collaboratively
  - Obtaining appropriate licenses for all usage scenarios
  - Ensuring all session participants understand licensing restrictions
  - Compliance with your jurisdiction's software licensing laws

### Questions

Before using a plugin in a collaborative SuperDAW session, contact the plugin vendor if you are unclear whether their license permits parameter values authored by a collaborator who does not hold a license for that plugin.
