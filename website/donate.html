Support SuperDAW

The program is free and always will be. No company, no investors, no paid tier and nothing to upsell you.

To be clear about what a donation buys: nothing. Every feature is available to everyone. There's no supporter build and no priority queue.

What it covers is unglamorous — code-signing certificates so the installer stops warning people, relay hosting for sessions that can't use a LAN, hardware to test against, and the time to keep building.

Help that isn't money.

Some of these are worth more than a donation — especially the testing, since collaboration bugs need more than one machine to find.

  • Star the repository It's how anyone discovers a project like this.
  • Report bugs Clear steps to reproduce, filed here.
  • Test a live session Get a few people into one project and try to break the sync.
  • Try your plugins VST3 hosting meets some unusual plugins. Say which ones misbehave.
  • Contribute code Read docs/ARCHITECTURE.md first and a pull request will go smoothly.
  • Tell another musician Word of mouth is the entire marketing budget.
