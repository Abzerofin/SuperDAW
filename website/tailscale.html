Remote collaboration with Tailscale

How to set up peer-to-peer SuperDAW sessions across the internet, with zero latency overhead compared to being on the same network.

The problem

SuperDAW's LAN mode is faster, but LAN means local network.

SuperDAW's peer-to-peer architecture is built for direct connection — the host and peers talk straight to each other with no relay in between. This is perfect on a LAN, but it doesn't work when you're in different cities. For now, there's a workaround.

The workaround

Tailscale makes your internet look like a LAN.

Tailscale is a mesh VPN — it puts all your devices on one virtual private network, and they see each other as if they're on the same LAN. SuperDAW's peer-to-peer code just works, unchanged.

Why this works

  • Mesh, not hub-and-spoke Machines talk directly to each other, not through a central server. Tailscale just makes the routing work.
  • End-to-end encrypted Your traffic stays encrypted between peers. Tailscale never sees your project.
  • Free tier is real You can connect up to 100 devices for free. No credit card, no time limit.
  • Works everywhere Firewalls, NAT, carrier-grade NAT — Tailscale's UDP hole-punching finds a path.

Setup

Getting it running in three steps.

  1. Install Tailscale on every machine that will collaborate. Get it for Windows, Mac, Linux or mobile.
  2. Sign in with any account (Google, GitHub, Microsoft, or a Tailscale account). You'll be assigned an IP on the Tailscale network — write it down.
  3. Start a SuperDAW session as usual. Click Collab → Start. Share the join code with your collaborators — it will encode your Tailscale IP, not your real one. When they join, they'll be connecting through the virtual network.

That's it.

SuperDAW has no idea Tailscale is there. It just sees machines on the same network and goes peer-to-peer. Latency is the same as being in the same room.

The limits

What Tailscale can't do.

Tailscale is a workaround, not a permanent solution. We're building a proper relay transport into SuperDAW so you don't need this extra step.

It's another tool to install

One more dependency, one more thing to troubleshoot if it breaks. We want SuperDAW to do this by itself.

It requires accounts

You have to sign in somewhere, even on the free tier. SuperDAW's whole point is no accounts at all.

Extra setup friction

One more thing to explain to collaborators who've never heard of a VPN. Most just want to share a code and make music.

When we ship the real thing

The relay-based transport is on the roadmap. For now, Tailscale gets you remote peer-to-peer sessions that work.
