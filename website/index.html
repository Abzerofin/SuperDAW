What it doesn't do

Three things it won't do.

A lot of what makes SuperDAW worth using is stuff it leaves out. None of these are missing features that'll turn up in a later version.

No

AI features

Nothing here writes your music for you, or "improves" it. The program does what you tell it to and that's all it does.

No

Accounts

No sign-up, no login, no profile to fill in. You hand someone a code and they're in.

No

Cloud dependency

Projects are single .sdaw files on your own disk. Nothing you need to open your own song lives on somebody else's server.

Capabilities

What's in it.

All of it syncs to everyone in the session, and all of it can be undone.

Real-time collaboration

Several people in one project at once, with live cursors and undo that's per-person. Work offline and it catches up when you reconnect.

Hover to see itSession panel

Everything is undoable

Every edit is a single operation underneath, so nothing can reach the other people in the session and then leave you unable to take it back.

Native low-latency audio

A WASAPI engine that falls back to Web Audio if anything goes wrong. What you hear while tracking comes out of the same callback that renders playback.

VST3 plugins, live

Plugins process inside the realtime callback and their latency gets compensated for, so a knob you turn is heard straight away and stays lined up with everything else.

Instruments & effects

Eleven effects (EQ, compressor, limiter, delay, reverb and the rest of the usual set) plus an analog synth, a sampler and a drum kit.

Hover to see itInsert chain

Piano roll & MIDI

Play a keyboard in live, record it, or drop in a .mid file. Timing is counted in whole ticks, so two machines never drift apart.

Hover to see itPiano roll

Mixer & automation

Fader, pan, mute and solo on every track, a master bus, volume automation that's accurate to the sample, and freeze for when a chain gets heavy.

Hover to see itMixer

Performance pads

An 8×8 launchpad you can play with the mouse, the computer keyboard or a MIDI grid. Everyone in the session hears what you play.

Hover to see itPad grid

Chat & comments

Chat, plus comments pinned to a particular clip or track. All of it saves inside the project file rather than on someone's server.

File Bay

Folders and waveform thumbnails. Drag things onto tracks, or drag files in from Explorer to import them.

Hover to see itFile Bay

Warp & tempo

Stretch a clip without moving its pitch, or move its pitch without stretching it.

Autosave & recovery

Unsaved work gets snapshotted as you go. If the interface hits a bug you get an error message, not an empty timeline.

Collaboration

How people join.

One person starts the session and passes around a 15-character code. Everyone else on the network connects straight to them, with no server sitting in between, so it's about as fast as this gets. Your own edits happen the moment you make them.

  1. Click Collab → Start. Your machine becomes the host.
  2. Send the code. It's short enough to read out over a call.
  3. They paste it into the launcher. That's the whole setup.

In a studio or a rehearsal room none of this needs setting up. No VPN, no account, no internet connection even, just the network that's already in the building. It's as much a tracking tool as a writing one: every machine records its own inputs into the same session, so a room can put up more mics at once than any single interface has inputs for, and somebody can be editing the takes while they land.

Working remotely? Until the built-in relay is finished, a mesh VPN like Tailscale puts everyone on one virtual network and the same thing works across it.

Get it

Install it, or build it yourself.

Once it's installed it updates itself, so this is a one-time thing.

Download the installer Browse the source 
# requires Node.js 20 or newer
git clone https://github.com/Abzerofin/SuperDAW.git
cd SuperDAW
npm install

npm run dev       # desktop app (Electron)
npm run dev:web   # UI only, in a browser
npm run test      # core test suite
